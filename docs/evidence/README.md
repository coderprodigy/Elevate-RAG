# Checkpoint evidence

The repository includes the [Phase 1 and Phase 2 verification summary](checkpoint-summary.json), the [dataset manifests and checksum audit](dataset-manifests.json), and the [post-cleanup test outcomes](checkpoint-verification.json). The summaries contain fixture outcomes, coverage totals, aggregate router validation, experiment-plan counts, study assumptions, and hashes of local evidence files. The dataset manifests include source revisions and counts. The published corpus text, question-level records, raw logs, model weights and credentials stay local.

Paths marked **local evidence** in the project docs are relative to the Atlas workspace. They refer to ignored files generated by the workflows in [Reproducibility](../REPRODUCIBILITY.md). The [checkpoint report](../PRE_PUSH_CHECKLIST.md) records the local archive and its verification commands.

The fixture outcomes and estimates have their own scope in the summary. See the [implementation audit](../IMPLEMENTATION_AUDIT.md) and [pending work](../PENDING_WORK.md) for the remaining research gates.
